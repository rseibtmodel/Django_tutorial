# Repositório de Pareceres & Teses Assimétricas

Esta pasta é o repositório oficial de dossiês estratégicos, análises de convexidade e teses de valor 10x gerados pelo **Estrategista de Impacto (`/impact` ou `/value`)**.

---

## 📋 Convenção de Nomenclatura dos Dossiês

Os pareceres salvos neste diretório devem seguir o padrão cronológico em `snake_case`:
```text
projeto_testes/teses/{YYMMDDNN}_tese_{slug_do_tema}.md
```
*Exemplo:* `26110301_tese_central_gestao_personas.md`

---

## 💎 A Tríade Padrão de Tese Convexa

Todo parecer de valor catalogado avalia:
- `💎 OURO ESCONDIDO`: O benefício ou ativo invisível gerado pelo sistema.
- `⚡ ALAVANCAGEM 10X`: O multiplicador concreto de capacidade produtiva humana.
- `🏰 FOSSO DE PROCESSO`: A barreira competitiva intransponível de longo prazo.

---

## 🔄 Fluxo de Governança Multiagente

1. **Avaliação:** O `/impact` formula a tese assimétrica e salva o parecer nesta pasta.
2. **Integração:** O `/doc_master` analisa o parecer e atualiza o `ROADMAP.md` e a pasta `specs/Ideias/`.
3. **Equilíbrio Dialético:** O `/architect` analisa conjuntamente o parecer do `/impact` (valor) e o laudo do `/critic` (risco) para desenhar os ADRs.
4. **Execução:** O `/coder` implementa as soluções com base na arquitetura homologada.
