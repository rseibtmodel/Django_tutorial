# Dossiês de Sessões de Brainstorm Dialético

Esta pasta é o repositório oficial de transcrições completas e laudos das sessões executadas pelo pipeline multiagente **/brainstorm**.

---

## 📋 Convenção de Nomenclatura dos Dossiês

Os relatórios salvos neste diretório seguem o padrão cronológico em `snake_case`:
```text
projeto_testes/brainstorms/{YYMMDDNN}_brainstorm_{slug_do_tema}.md
```
*Exemplo:* `26110301_brainstorm_gestor_financas_viscosas.md`

---

## 🔄 Conteúdo Obrigatório do Dossiê

1. **Cabeçalho & Metadados:** Data, operador, ideia bruta original e objetivo.
2. **Fase 0 (Divergência Pura - Oráculo):** A rajada de fragmentos ontológicos e a anomalia selecionada para o debate.
3. **Fase 1 (Mesa de Discussão):** Transcrição integral das 3 rodadas dialéticas:
   - Rodada 1: Diagnóstico Inicial Independente (/hacker, /critic, /impact, /ux_designer, /architect).
   - Rodada 2: Confronto Cruzado & Tréplicas diretas.
   - Rodada 3: Posições Finais, Concessões & Consenso.
4. **Fase 2 (Síntese do Alquimista):** Cópia do JSON gerado com Score 0-10, classificação e o link para o arquivo persistido em `alquimista_ideias/`.
5. **Handoff e Próximos Passos:** Recomendações para `/architect`, `/doc_master` e `/coder`.
