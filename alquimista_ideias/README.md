# Laboratório de Síntese Alquímica (alquimista_ideias/)

Este diretório é o repositório oficial de persistência compulsória de ideias refinadas, transmutadas e pontuadas pelo **Alquimista (`/alquimia` ou `/alquimista`)**.

---

## 📂 Organização por Faixa de Score

O Alquimista organiza seus artefatos JSON nas seguintes subpastas:

- `ouro/`: Ideias com **Score 9.0 a 10.0** (Altamente assimétricas, inovadoras e executáveis com blindagem técnica).
- `solidas/`: Ideias com **Score 7.0 a 8.9** (Propostas muito sólidas, com diferencial claro e riscos calculados).
- `medianas/`: Ideias com **Score 4.0 a 6.9** (Conceitos medianos com atrito considerável ou valor moderado).
- `autopsias/`: Ideias com **Score 0.0 a 3.9** (Conceitos natimortos com falha estrutural insuperável, catalogados com autópsia e resíduo reaproveitável).

---

## 📋 Padrão de Nomenclatura dos Arquivos

Cada síntese é salva no formato JSON estrito:
```text
alquimista_ideias/{subpasta}/{YYMMDDNN}_alquimia_{score_inteiro}_{slug}.json
```
*Exemplo:* `alquimista_ideias/ouro/26110301_alquimia_95_interface_sangria_monetaria.json`

---

## ⚗️ Regra de Ouro do Alquimista
*"Nenhuma ideia é descartada em memória. O chumbo é analisado no laboratório de autópsias e o ouro é lapidado preservando o núcleo intransgressível da ideia original."*
